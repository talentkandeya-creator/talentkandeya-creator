## My Software Developer Learning Roadmap

I'm building a strong foundation one step at a time:

1. **Computer science and programming fundamentals** — [CS50x](https://cs50.harvard.edu/x/) covers problem-solving, algorithms, data structures, C, Python, SQL, and web basics. Practice the problem sets instead of only watching the lectures.
2. **Git and GitHub** — learn commits, branches, pull requests, and collaboration with [GitHub Skills](https://learn.github.com/skills).
3. **Web development foundations** — work through [The Odin Project: Foundations](https://www.theodinproject.com/paths/foundations/courses/foundations) to learn HTML, CSS, JavaScript, Git, and how to build projects. Use [MDN's web development guides](https://developer.mozilla.org/en-US/docs/Learn_web_development) as a reference.
4. **Databases** — practice queries and relational database concepts with [SQLBolt](https://sqlbolt.com/).
5. **Full-stack development** — after becoming comfortable with JavaScript and the web basics, continue with [Full Stack Open](https://fullstackopen.com/en/) for React, Node.js, APIs, testing, and TypeScript.
